# GuardianX – AI-Powered Emergency Detection & Response System

## About the Project
GuardianX is designed to identify potential emergencies and help notify registered emergency contacts.

## Features
- Emergency severity assessment
- Emergency incident management
- MySQL database integration
- Emergency response support

## Technologies Used
- Java
- MySQL
- HTML
- CSS
- JavaScript

## Objective
To improve emergency awareness and support faster responses through technology.
